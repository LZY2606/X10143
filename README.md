# 租约调试台

一个纯 Python 的确定性分布式租约重放工具。所有系统行为都由整数毫秒虚拟时钟驱动，不使用真实网络、睡眠线程或外置存储。

## 能力

- 创建多个客户端，配置各自的墙上时钟偏移与网络延迟。
- 安排 `acquire`、`renew`、`release`、`read` 和网络分区。
- 服务端按模拟时间裁决租约，客户端偏移只用于展示。
- fence token 单调递增，续租和释放携带 fence token 与幂等键。
- 迟到旧响应按客户端请求序号丢弃，不能覆盖更新认知。
- 过期后的旧 token `release` 幂等成功，但不能释放后来的持有者。
- 分区恢复时按原定到达时刻与稳定序号处理队列请求。
- 快照、分叉、分支隔离、JSON 持久化和确定性导入导出。
- 页面支持拖动时间轴、单步、快进、客户端视角、请求详情和不变量面板。

## 安装

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[test]'
```

## 演示

```bash
.venv/bin/pytest -q
.venv/bin/python -m leasedebug --host 127.0.0.1 --port 5224
```

打开 <http://127.0.0.1:5224>，页面标题为“租约调试台”。

数据默认写入当前目录 `.leasedebug-data.json`，可用 `--data` 指定其他路径。

## 确定性规则

- 请求延迟在发送时固化到请求事件中。
- 同一时刻事件使用全局稳定序号决出处理顺序。
- 分区期间到达的请求保留 `scheduled_arrival_ms`，恢复重放时仍按该时刻裁决。
- 导出的实验包含全部事件、快照和分支，重新导入后 fence token、请求顺序和摘要保持一致。
