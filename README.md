# 租约调试台（leasedebug）

一个用纯 Python（标准库）实现的分布式租约时序重放调试台。创建若干客户端，
设置各自的时钟偏移与网络延迟，安排 `acquire` / `renew` / `release` /
`read` 与网络分区事件；系统在单调的虚拟时钟上重放完整时序，展示服务端
租约状态、各客户端"以为"的状态，以及每个请求的发送、到达、响应时刻。

不使用真实网络集群或外部存储；持久化只用本地 SQLite。

## 安装与演示

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[test]'
.venv/bin/pytest -q
.venv/bin/python -m leasedebug --host 127.0.0.1 --port 5224
```

浏览器打开 <http://127.0.0.1:5224>，页面标题为「租约调试台」，首次启动
会自动载入一个覆盖续租、忙等、分区过期、旧认知释放、幂等重送、同时到达与
迟到旧续租的演示实验。数据库默认写在当前目录 `.leasedebug.db`
（`--db` 可改）。

## 页面能力

- **可拖动时间轴**：滑块 / 单步 / 快进 / 到结尾；泳道展示每个客户端的
  发送、到达、响应点，服务端泳道展示持有区间，分区用斜纹带标出。
- **客户端视角切换**：查看任一客户端对每个资源的认知（holding/busy/
  released），并用其墙上时间（模拟时间 + 时钟偏移）标注"它以为是否已
  过期"——墙上时间只用于展示，不参与裁决。
- **请求详情**：点击任意请求，查看稳定序号、发送/到达/计划投递/实际
  投递时刻、fence、幂等键、完整服务端响应。
- **不变量面板**：实时列出 6 条不变量及违规证据。
- **事件编辑**：新建客户端、逐请求覆盖请求/响应延迟、制造网络分区。
- **保存分叉 / 导出 / 导入**：分叉创建独立的子实验；导出为单个 JSON，
  导入后 fence token、处理顺序与最终摘要完全一致。

## 模拟语义

所有时间都是整数毫秒，模拟时间从 0 单调递增，`SimClock` 不允许回拨，
测试与服务全部跑在虚拟时钟上。

- **服务端时间裁决**：请求在其逻辑到达时刻 `send + 请求延迟` 被裁决；
  同一资源任一时刻最多一个有效持有者。持有区间为半开区间
  `[start, expiry)`，因此恰好在过期时刻到达的 `acquire` 合法。
- **fence token**：同一资源每次重新授予得到严格递增的 fence；续租不
  换 fence。客户端续租/释放默认携带其当前认知中的 fence，也可显式指定。
- **幂等键**：键空间为 `(client, key)`。同一键回放首个已存结果，不会
  重复执行；同键但操作/资源不同返回 `idem_key_conflict`。
- **迟到旧响应防护**：客户端同时用稳定序号和 fence 双重判断，旧续租
  响应晚到时记入 `ignored`（`older_seq` / `older_fence`），不能覆盖
  更新的认知。错误响应与 `read` 不改变资源认知。
- **release**：自己持有且 fence 匹配才真正关闭区间；租约过期后再
  release 仍幂等成功（`already_expired`）；后来持有者在场时旧持有者的
  release 不会影响对方（`already_expired` / `stale_fence`）。
- **网络分区**：分区只推迟响应回到客户端的时刻，不改变服务端处理顺序。
  服务端始终按 `(arrival, 稳定序号)` 全局处理；恢复时队列中的响应按该
  顺序出队，并保留原定到达间隔（`heal + (arrival_i - arrival_0) +
  回程延迟`），不会在重连时刻挤成同一时刻。
- **快照与分叉**：`snapshot_at_request(k)` 在处理完第 k 个请求（含此前
  所有投递）序列化完整服务端状态（fence、活跃租约、幂等表、持有区间、
  客户端认知）。子分支共享此前事件，对后缀事件施加延迟等 delta，从独立
  的快照状态继续，后续状态与父分支完全隔离。

## 代码结构

- `src/leasedebug/engine.py`：虚拟时钟、调度、服务端裁决、认知更新、
  快照/分叉、不变量检查（核心）。
- `src/leasedebug/store.py`：SQLite 持久化与导出/导入。
- `src/leasedebug/webapp.py`：基于 `http.server` 的 REST API 与静态页。
- `src/leasedebug/demo.py`：内置演示实验。
- `src/leasedebug/static/`：单页前端（原生 HTML/CSS/JS，无构建步骤）。
- `tests/`：全部使用虚拟时钟的 pytest。

## 测试

`.venv/bin/pytest -q` 覆盖：单调虚拟时钟、同时到达按稳定序号决胜、
过期半开边界、迟到旧续租响应、释放后再获取与旧持有者释放安全、
分区队列顺序与间距、幂等重送与键冲突、快照分叉隔离、SQLite 重启恢复、
导出/导入一致性、HTTP API 与页面标题。
